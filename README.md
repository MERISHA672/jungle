
# 🌴 Jungle Escape

A 3D endless-runner game built with JavaScript, Three.js, and Vite.

## 🎮 About the Project

Jungle Escape is an adventure game where players run through a jungle, avoid obstacles, collect coins, and try to achieve the highest score.

## ✨ Features

- 3D jungle environment
- Endless running gameplay
- Three-lane movement
- Jumping and sliding mechanics
- Obstacles and collectible coins
- Score and best-score tracking
- Keyboard and mobile swipe controls
- Responsive 3D rendering

## 🛠️ Technologies Used

- JavaScript
- Three.js
- Vite
- HTML5
- CSS3

## 🚀 Getting Started

### Requirements

- Node.js
- npm
- Git

### Installation

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Enter the project folder:

```bash
cd jungle-escape
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in your terminal.

## 🎯 Controls

| Action | Control |
|---|---|
| Move left | Left arrow / A |
| Move right | Right arrow / D |
| Jump | Up arrow / Space |
| Slide | Down arrow / S |
| Mobile movement | Swipe |
